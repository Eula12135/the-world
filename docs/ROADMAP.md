# 功能规划与设想（Roadmap）

本文档用于沉淀版本计划评估或已落地的功能方案记录。

---

## 1. 可分享角色卡（含立绘与语音） — ✅ 已实装

### 目标
参考 Honey Select / SillyTavern 的角色卡分享体验，支持将单个角色卡（无论是独立角色还是作品下角色）打包导出为可分享文件（`.twcard.json` 或内嵌 `tEXt` 元数据的 `.png` 角色卡，同时兼容导入 TavernCard v2）；他人导入后即可直接获得完整角色设定、头像立绘与对应声线，用于角色扮演对话。

### 角色卡包含内容
- **文本设定**：角色名、身份、性格、当前状态、关系备注、补充笔记、自定义 `systemPrompt`。
- **视觉形象**：压缩后的头像/立绘图片（`avatarImage`）与配色（`avatarColor`）。
- **语音配置与样本**（见下方分层方案）。
- **安全过滤**：导出时严格剥离所有 API Key、私有服务地址凭据及无关会话记录。

### 声音共享方案（适配 BYOK 模式）
由于本应用为纯本地自带密钥（BYOK）架构，不同用户使用各自的 API Key，声音按来源分三类处理：

1. **厂商公共预设音色**（如硅基流动 CosyVoice2 预设、OpenAI / MiniMax 公共音色）
   - 直接在角色卡中保存 `providerId`、`model`、`voiceId` 以及语速/音高/语气指令（`rate` / `pitch` / `styleInstruction`）。
   - 对方配置了同一厂商 API Key 时，导入即可直接发声。

2. **云端克隆 / 定制音色**（如上传参考音频生成的私有 `speech:xxx`）
   - 此类 `voiceId` 绑定原创建者 API 账号，跨账号直接调用会失败（403/404）。
   - **解法**：角色卡内额外打包一段 **5~10 秒压缩参考音频**（MP3/Opus，约 30~60 KB）及对应参考文本（`sourceText`）。
   - 对方导入后：
     - 即使尚未配置 TTS Key，也能**离线试听**这段角色参考语音；
     - 若配置了支持声音克隆的 TTS 厂商，点击「复刻到我的账号」即可用自己的 Key 自动上传样本生成新 `voiceId`，还原相近音色。

3. **提示词捏声线（Voice Design）**
   - 保存音色描述词（配方）及生成的 5~10 秒试听样本；导入后既可按描述重新生成，也可直接基于样本一键复刻。

4. **优雅降级**
   - 若对方未配置对应厂商 Key，保留离线试听与 `styleInstruction`（语气描述），提示用户选择替补音色或回退系统原生朗读。

### 分享载体格式
- **主力格式（`.twcard.json` 或压缩包）**：适合微信/QQ 文件直传、网盘与社区分享，不被图片压缩破坏。
- **可选格式（PNG 角色卡）**：将角色卡 JSON 写入 PNG 的 `tEXt` / `iTXt` 元数据块，实现「存图即存角色」（需在导出时提示：小红书/微信直接发普通图片会被平台转码剥离元数据，需通过原图/文件传输）。

### 合规与工程边界
- **声音权合规**：导出界面需明确提示，参考音频仅限打包 **AI 生成的原创声线样本**或已获授权音频，避免传播未经授权的真人/明星/商用声优克隆声音。
- **导入校验**：复用并强化导入字段归一化与体积限制（防止恶意超大图片/音频或缺失字段导致异常）。
