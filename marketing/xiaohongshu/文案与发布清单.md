**正文**

> 自己写长篇、养 OC 的时候，最头疼的三件事：
> 设定越写越乱、AI 聊久了就失忆串戏、又不太敢把大纲传上云。
>
> 所以干脆做了个纯本地的小工具 **The World**，Windows 和安卓都能用，免费开源。
>
> ✨ 四个我最常用的功能（图上都有截图）：
>
> 1️⃣ **跨时间维度的人物关系图谱**
> 不只是画静态关系网。可以按时间线切片记录关系变化（前期挚友 → 某事件后反目 → 后期联手），拖时间轴就能看全员关系一步步演进，还能一键播放"演变"。写群像、写反转特别直观。
>
> 2️⃣ **把已有设定一键拆成角色卡 + 大纲**
> 支持导入 Word / txt / md 文档，自动整理成带目录的设定集，也可以让模型抽出角色卡、时间节点和关系网。（这一步要配好 API Key）
>
> 3️⃣ **直接和自己的 OC 对话，防剧透**
> 内置"扮演角色卡"模式，发给模型的上下文只包含当前时间点之前的关系和最相关的设定章节；聊长了还能一键浓缩前情摘要，不容易串戏，也省 Token。
>
> 4️⃣ **纯本地、无服务器、无账号**
> 不收集任何数据，设定和聊天记录都只在你自己的设备里。需要自己填 API Key（DeepSeek / 硅基流动 / Kimi / 智谱 / 本地 Ollama 都行），也支持导入 DeepSeek 官方导出的聊天记录。
>
> 项目在 GitHub / Gitee 完全开源（MIT 协议），搜 **The World** 就能找到源码和安装包。
>
> 个人业余时间做的，肯定还有很多可以优化，想要什么功能欢迎评论区说，听劝持续更新 🙌
