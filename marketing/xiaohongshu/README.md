## 视频是怎么录的（真机，不是画的）

- 设备：小米 15（1200×2670），通过 adb 投屏录制 `screenrecord`，未做任何界面造假。
- 流程：导入演示世界观 → 角色对话里点「重新生成」→ **DeepSeek 实时生成回复**（手机上真的配了 API Key，这一段是真实推理输出）→ 打开「世界观与时间点」弹层选时间点 → 关系图谱「播放演变」。
- 后期：抽帧重排（生成过程 2.3× 加速）、1080×1920 竖屏包装、三段字幕、程序合成的 BGM。
- 素材与工程：`C:\AI\promo\phone`（不在仓库内，避免给项目加依赖）。

## 图文素材是怎么做的

- **截图来自真实运行的网页版**：`vite dev` + Chromium，按桌面 1440×1080 截图，没做 UI 造假。
- **演示世界观《白昼钟楼》是虚构的**，5 角色 / 3 时间节点 / 6 条跨时间关系，写进 IndexedDB 后由 App 正常渲染。
- **两处内容是演示文案**：P4 里「陆昭」的对话回复是手写台词（做图文时没配 Key），P2 的角色卡是预置数据而非真的点了一次「AI 智能提取」。
  - 想换成真实输出：手机视频里那段就是真跑的，可以直接截那一帧替换 P4。
